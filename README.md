 ComSen 硬件组招新作品 - STM32 触摸计算器工程

 一、 项目概述
本项目为 ComSen 实验室 2026 年硬件组招新作品。
工程基于 STM32F103C8T6 主控、LCD1602 液晶显示屏以及 TTP229 电容触摸芯片，实现了一个具备基本四则运算功能的计算器。

二、 已完成的功能与模块
在本次招新中，我完整走通了从环境配置、硬件焊接、硬件排障到软件编译烧录的全流程。具体完成内容如下：
 1. 硬件焊接与底层排障模块（独立完成）
（1)焊接工作：独立完成了 STM32 核心板排母、LCD1602 屏幕 16Pin 排母、以及 TTP229-BSF 芯片的焊接。
（2)微短路排障：在测试中发现 H1 和 H3 排母存在 470Ω 的微短路。通过酒精清洗、结合万用表逐脚测量，最终使用吸锡线成功清理了短路的引脚，排除了短路隐患。
（3)物理故障定位：在最终调试中发现系统无法完美读取触摸，经排查，定位到 U1 芯片的 13 号引脚（SCL 时钟线）的 PCB 焊盘在到手的时候就已经歪了，在焊接过程中彻底脱落，导致时钟信号断路。
2. 软件编译与烧录模块（独立完成）
（1)配置了 WSL Ubuntu 环境及 `arm-gnu-toolchain` 交叉编译链。
（2)使用 Git 进行代码版本管理。
（3)执行 `./build.sh Release` 成功编译出 `software.hex` 固件。
（4)使用 ST-Link 及 STM32CubeProgrammer 成功将固件烧录进芯片。
（5)功能表现：拔掉 ST-Link 使用 Type-C 独立供电后，系统成功启动，LCD 屏幕显示 `READY` 。
 3. 软件拓展与指针实践模块（独立编写，未烧录）
（1)在阅读源码过程中，为了理解底层驱动原理，我自学了 C 语言指针。
（2)独立编写了 `pointer_AC_demo.c` 文件（未修改学长原工程，以防破坏系统）。
（3)通过 `char *p` 和 `p++` 指针偏移的方式，直接操作内存地址，实现了模拟 LCD 显示缓冲区清空（AC 键）的逻辑。

三、 使用的库文件
本工程在软件层面直接复用了实验室提供的预编译库（未做破坏性修改）：
*   `liblcd1602.a` （LCD 屏幕显示驱动）
*   `libttp229.a` （触摸芯片读取驱动）
*   `libcalculator_engine.a` （计算逻辑引擎）

 四、 存在的问题与反思
1.当前缺陷：因 U1 的 SCL 物理焊盘脱落，导致触摸按键出现乱码或无效。
2.反思：这次招新让我深刻认识到了硬件工艺的脆弱性，虽然作品未能完美计算，但我掌握了万用表排错、交叉编译、固件烧录等核心技能，期待能在实验室学习专业的技术与底层驱动开发。
